## Episode format (what to keep doing)
- Cold open / intro clip recorded for the episode ("welcome to episode N, in this video we go over ...").
- Then day-by-day check-ins in shooting order; each check-in starts with context ("so it is the next day, 8am...").
- Keep the real moments (tired, school, family, doubts, decisions); cut dead air, false starts, repeated takes, "I'll show you
  in a sec" set-up time, and anything private (client names/numbers the user doesn't want public).
- Outro: short "that's it for episode N".
